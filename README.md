# FloatingEye — летающий глаз для Paper 26.1.2

Один огромный глаз на весь сервер: парит высоко в небе, кружит над игроками, моргает, меняет эмоции,
иногда спускается к случайному игроку и посматривает на него. Он **материальный**: упирается в блоки
и скользит вдоль них, а не проходит сквозь. Ресурспак с текстурами лежит **внутри jar** и сам раздаётся игрокам.

## Установка без компьютерной возни (через GitHub)
1. Зарегистрируйся на github.com и создай **публичный** репозиторий (New).
2. Распакуй этот архив и загрузи его СОДЕРЖИМОЕ в репозиторий (Add file -> Upload files, перетащи все файлы и папки, включая `.github`). Нажми Commit.
3. Открой вкладку **Actions**, подожди 2-3 минуты, пока сборка станет зелёной.
4. Справа на главной странице репозитория открой **Releases -> FloatingEye (latest)**. Там два файла:
   - `FloatingEye-1.0.0.jar` - скачай и положи в `plugins/` сервера;
   - `eyesky-pack.zip` - его ссылка нужна для конфига (ПКМ -> копировать адрес ссылки).
5. Запусти сервер один раз, открой `plugins/FloatingEye/config.yml`, вставь ссылку в `pack.url`, сохрани, перезапусти.

(Свой компьютер: JDK 25 + Gradle, команда `gradle build`.)

## Команды (право `eyesky.admin`, по умолчанию op)
- `/eye status` — состояние
- `/eye emotion <normal|blink|happy|angry|sad|surprised|sleepy> [сек]`
- `/eye visit [игрок]` — отправить глаз к игроку
- `/eye laser [игрок]` — лазер: глаз зависает, 5 секунд отсчёта, потом луч прямо вниз выжигает воронку (с игроком — сначала подлетает к нему). Настройки в `laser:` в config.yml
- `/eye shoot` — смотришь на точку (до 400 блоков), пишешь команду: глаз подлетает туда, заряжается и бьёт лазером
- `/eye summon` — перенести глаз в небо над собой
- `/eye pack` — переотправить ресурспак всем
- `/eye reload` — перечитать настройки

## Текстуры
Все эмоции лежат в ОДНОМ листе `textures/item/s.png` (сетка 4x2, кадры 256x256: NORMAL, BLINK, HAPPY,
ANGRY, SAD, SURPRISED, SLEEPY). Этого файла **нет в репозитории**: GitHub рисует его сам при каждой сборке
скриптом `tools/generate_textures.py`. Имена моделей — просто цифры, так что по файлам пака не понять, что внутри.
Важно: клиент игрока всё равно скачивает пак целиком, так что спрятать текстуры от того, кто сам полезет в кэш
игры, нельзя — это только защита от случайного взгляда в репозиторий/релиз.

## Заметки
- Рассчитан на Обычный мир (Overworld). В Незере потолок из бедрока — глаз будет упираться в него.
- Дальность видимости ограничена трекингом сущностей сервера (`spigot.yml` → `entity-tracking-range`);
  если глаз пропадает на расстоянии, увеличь значение.
- Проект написан без возможности собрать и запустить его у автора — если при сборке будет ошибка, пришли лог.
